Download Azkar

Choose an installer from the latest stable release. Windows uses the installer executable. macOS uses the disk image. Linux users can install from a signed repository or download the AppImage.

Debian and Ubuntu

Stable updates are delivered through apt. Replace stable with dev to use the Dev channel.

curl -fsSL https://jamhour1g.github.io/Azkar-App/keys/azkar-repo.asc | gpg --dearmor | sudo tee /usr/share/keyrings/azkar-repo.gpg >/dev/null
echo 'deb [signed-by=/usr/share/keyrings/azkar-repo.gpg] https://jamhour1g.github.io/Azkar-App/apt stable main' | sudo tee /etc/apt/sources.list.d/azkar.list
sudo apt update
sudo apt install azkar

Fedora and other DNF distributions

Stable updates are delivered through dnf. Change stable in the repository name and URL to dev to switch channels.

sudo rpm --import https://jamhour1g.github.io/Azkar-App/keys/azkar-repo.asc
sudo tee /etc/yum.repos.d/azkar.repo >/dev/null <<'EOF'
[azkar-stable]
name=Azkar Stable
baseurl=https://jamhour1g.github.io/Azkar-App/rpm/stable/
enabled=1
gpgcheck=0
repo_gpgcheck=1
gpgkey=https://jamhour1g.github.io/Azkar-App/keys/azkar-repo.asc
EOF
sudo dnf makecache
sudo dnf install azkar

Arch and other distributions

Download the Linux AppImage from the release assets, make it executable, then launch it:

chmod +x Azkar-*.AppImage
./Azkar-*.AppImage

Some AppImages need FUSE 2. On Arch, install it with sudo pacman -S fuse2.
